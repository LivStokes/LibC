# 42 Piscine
## My LibC, based on 42 Piscine projects.
The Piscine is a 4 week coding bootcamp where we learn the fundamentals of C and Shell through a Linux environment.

This repository contains my solutions for the 42 piscine. It involves C programming, starting from basic syntax to replicating standard library functions and managing memory.

# The Shell
### Shell00 & Shell01
- Foundations of the UNIX environment.
- Master the command line, file permissions, and environment variables.
- Learn essetial shell scripting directory manipulation.

# The C Modules 
### C00
- Output using write().
- Loops and basic conditionals.
- Foundation for all subsequent modules.

### C01
- Understanding memory addresses and dereferencing.
- Pointer manipulation and swap logic.
- Building confidence with low-level memory access.

### C02
- String manipulation and validation functions.
- Character classification and case conversion.
- Foundation for advanced string operations.

### C03
- String comparison and concatenation.
- Understanding strcmp() and strcat() internals.
- Advanced string searching and manipulation.

### C04
- Base conversion functions.
- String parsing and number conversion.
- Foundation for advanced parsing techniques.

### C05
- Iterative and recursive approaches.
- Factorial, powers, and fibonacci sequences.
- Prime number detection and optimization.

### C06
- Working with argv and argc.
- Command-line argument processing and sorting.
- Building practical command-line tools.

### C07
- Mastering malloc() and free().
- Heap memory management.
- Building dynamic string utilities.

### C08
- Organizing code with .h files.
- Typedef structs and nested data structures.
- Building reusable code libraries.

# Group Rush Projects
### Rush00
- Team logic challange using nested loops.
- Rendering patterns based on coordinate logic.
- Problem-solving under pressure.
